# Learning Resources and Team Workflow

The following resources are useful for learning Cloud Computing and software development.

1. Python Documentation: https://docs.python.org/3/
2. Git Documentation: https://git-scm.com/doc
3. GitHub Documentation: https://docs.github.com/
4. AWS Documentation: https://docs.aws.amazon.com/
5. AWS Cloud Computing: https://aws.amazon.com/what-is-cloud-computing/

## Basic Development Workflow

I learned the basic workflow followed by software development teams:

1. Create a feature branch from the main branch.
2. Write or update the application code.
3. Test the changes locally.
4. Add and commit the changes using Git.
5. Push the feature branch to GitHub.
6. Create a Pull Request.
7. Review and merge the Pull Request into the main branch.
8. Pull the latest changes into the local main branch.

## Good Development Practices

- Write clear commit messages.
- Keep project files organized.
- Test code before pushing changes.
- Never upload passwords, API keys or other secrets to GitHub.
- Use README files to explain projects.
- Keep documentation updated.

## Conclusion

Official documentation helps developers learn tools and solve problems. Git and GitHub help teams manage code changes and collaborate on projects.
